# Blackjack — relances et soutenabilité

Expérience Monte Carlo explorant la réserve commune de relances (0 / 4 / 8) sur 8 tours, avec 4d6 et deux politiques heuristiques.

- `simulate.py` : simulation reproductible.
- `results.json` : résultats générés avec 50 000 courses par configuration, graine 20261117.
- `REPORT.md` : hypothèses, résultats, interprétation et limites.

Statut : expérimental. Ne constitue pas une décision de design ni une modification du GDD.
